# Clinic website

Informational site for a medical clinic. Edit `lib/clinic.ts` to change the name, services, physicians, qualifications, hours, contact details, and brand colours. Values in square brackets are placeholders and are not treated as confirmed facts.

```sh
npm run dev
npm run lint
npm run build
```

Replace `public/images/hero.jpg` with a photograph of the clinic, then update the image description and credit in `lib/clinic.ts`.
